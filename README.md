SailWatchPro extends Expedition Marine above-deck with a modern, touch-first iOS interface for iPad, iPhone, and Apple Watch. It synthesizes real-time data into clear, actionable insights and advisories — helping you make faster, more confident decisions on the water.

---

## Key Pillars

- **Race Management** — Pre-start timer and line ping controls with start line visualization, course marks, competitor tracking, sail and crew change event logging, and fully customizable dashboards
- **Wind & Weather Analytics** — Boat instruments + buoys + GRIB fusion, real-time trend analysis using advanced signal processing to identify oscillations, shifts, and building patterns, divergence tracking, and confidence levels
- **Data Management** — Full access to all Expedition channels plus computed channels with 5/10/15-minute averaging — including rolling performance analytics and a 6-hour wind history that syncs across all devices on the boat
- **Strategic & Tactical Advisories** — Smart, actionable alerts continuously monitor your instruments, wind, and weather — recommending sail changes, flagging current push and leeway, tracking barometric pressure trends, GRIB accuracy, dew point risk, and layline overstand — so you can focus on steering and tactics, not watching gauges

### Coastal Effects

The Wind view includes a Coastal Effects section that predicts the likelihood of sea breeze, land breeze, and friction shift effects on your racing area. Uses Open-Meteo (free, no account required) — an internet connection is required. The nearest coastal land point is determined automatically from the boat's GPS position. Data refreshes once per hour; tap the refresh icon in the card header to force an immediate update.

## Technical Highlights

- GRIB parsing via ECMWF ecCodes bridge
- Advanced signal processing using Morlet wavelet transforms for wind pattern analysis
- 5/10/15-minute averaging engine for any channel
- Two-way Expedition Marine integration
- Coastal Effects predictions via Open-Meteo (internet connection required)
- Night mode with red tint for night vision preservation

---

## Requirements

- **iPad / iPhone:** iOS 18.5+
- **Apple Watch:** watchOS 11.5+
- **Mac (Apple silicon):** macOS 15.6+
- **Expedition Marine:** 12.5.11+ (latest encouraged)
- Reliable boat WiFi
- NMEA 2000 Ethernet Gateway required for competitor tracking via AIS
- Internet connection required for Coastal Effects wind predictions (all other features work fully offline)
